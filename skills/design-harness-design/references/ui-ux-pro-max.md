# UI/UX Pro Max：按问题取用

仅在项目依据不足以回答当前交互、图标、信息层级或可访问性问题时加载。先按 [来源约定](sources.md) 读取 [上游最新指导入口](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/HEAD/src/ui-ux-pro-max/templates/base/skill-content.md)，需要数据时从当前 README/目录定位相关领域；不分发整套数据库或固定版本摘要。

## 对应当前设计阶段

| 当前问题 | 取用方向 | 在 Harness 中的落点 |
| --- | --- | --- |
| 主流程或分支的操作、导航、反馈、恢复 | 与该问题匹配的 UX/平台指导 | 当前原型片段与逐题取舍，不重新生成完整设计系统 |
| 图标、信息密度、颜色语义与阅读负担 | 图标、布局、色彩和可访问性规则 | 已确认项目风格内的局部调整，配合 Library 复用 |
| 视觉细化后的检查 | 当前平台和输入方式对应的规则 | 目标尺寸截图、原型走查；产品运行检查单独表达 |

## 适配边界

- 先明确一个具体问题，取最小相关指导；核对建议是否适用于实际产品、平台、输入方式和使用距离。不预设 React Native、手机尺寸或一律套用某个平台的触控单位。
- 项目已确认规则与真实资产优先。现有项目不强制运行 `--design-system`、另建色板或重选字体；建议与项目约束冲突时给出依据和取舍，不自动覆盖。
- 可在线阅读规则；已具备的检索工具可辅助定位。使用方法不要求安装上游 CLI、Python、其他 Skill 或运行脚本，也不执行其本地持久化、hooks、快照和发布流程。
- 原型设计、实际产品行为与无障碍运行结果分开验证。短标签是否清楚、图示是否准确需要看真实画面，不能由检查清单自动判定。
- 与 [Impeccable](impeccable.md) 按问题互补，不在每个阶段强制跑两套完整审计。取得的来源、适用理由与读取日期留在对话；未能获取最新内容时明确限制。
