# 预览、Live 与固定交付

## 运行与检查

在目标设计工作区运行：

    npm ci
    npm run dev
    npm run check
    npm run typecheck

预览服务只监听 127.0.0.1；默认端口 4173，可用 npm run dev -- --port 4174。
工作台与产品 iframe 隔离样式，iframe 的实际宽高决定响应式布局；缩放仅用于工作台摆放。
页面和场景变化在同一预览中体验。实际键盘、焦点、输入、滚动、恢复和材料操作必须在浏览器验证。

## 预览优先

默认展示主画布、必要控制和紧凑的悬浮工具入口。点击画布上的「交互说明」「Live 调整」「定位反馈」打开对应辅助面板，再次点击可收起，面板内也可切换工具。
桌面使用侧边覆盖式抽屉，小屏使用底部浮层；入口和面板均脱离画布布局，不改变实际分辨率、缩放或位置，也不重置产品状态。
关闭按钮或工作台 Esc 可收起面板；未保存调参和反馈草稿保留。点选模式中的预览 Esc 同时结束点选，正常产品键盘交互不受接管。
本地与离线交付采用相同布局；离线只能下载调参和反馈，不能写回源目录。

## 迭代

- 用「点选界面」取得稳定定位并打开对应 Live 区域，切换到「说明」查看关联依据，或到「反馈」复制带定位的信息。
- 用「对比方案」同时查看两个候选；两侧使用相同初始场景与视口，操作状态各自独立。
- 已登记参数即时预览；点击「保存候选参数」才写回文件。参数文件被外部修改时拒绝覆盖，刷新后重新比较。
- 自由布局、交互、图形和文案由 Agent 修改 React；保存源码后自动重载。未保存参数暂缓重载，先保存或恢复。
- 本版提供自身的最小 Live 链路，不安装 Impeccable、hooks 或后台任务。用户已有工具按其明确范围使用；不宣称支持任意 DOM 到 TSX 的自动反向编辑。

校验检查协议和全部页面/候选构建，阻止越界引用、重复协议 ID、失效锚点与非法参数。实际 DOM 的重复定位和未出现的说明目标由预览提示。
用户偏好、图像质量及验收不能由脚本推断。

## 导出与冻结

    npm run export -- <需求ID> v1
    npm run verify -- releases/<需求ID>/v1

index.html 内嵌脚本、样式、通过 ESM 导入的图形/字体与说明，不依赖 CDN、本地服务或业务后端。可复制单文件离线分享。
sources/ 保存需求、固定基础、模板源码、依赖清单和锁文件，release.json 保存 SHA-256 清单。HTML 包含实际运行依赖；源码重建需要按锁文件安装依赖。
已有版本拒绝覆盖，源码变化生成新交付版本。公共基础升级用新需求版本承接，不回改历史交付。
导出只生成快照，acceptance 不自动写为已验收。真实验收记录链接对应交付与依据。
离线版本不写回源目录，可下载参数文件和定位反馈供后续 Agent 承接。
截图用于视觉检查，交互仍以可运行 HTML 为交付。
