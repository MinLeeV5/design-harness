# 资料整理任务

这是一份合成数据示例，用于验证设计交付链路。实际需求应替换目标、规则与内容。

## 目标 {#goal}

让使用者交代整理目标，理解执行过程，并取得可检查的结果。

## 输入与校验 {#input}

任务主题为必填。空白提交显示字段错误，保留用户输入；修正后可再次提交。

## 提交规则 {#submit}

仅显式点击「开始整理」创建本地演示任务。运行中禁止重复提交。

## 运行反馈 {#progress}

显示接收、整理、生成结果三个阶段。示例采用本地定时反馈，不代表真实 Agent 执行。

## 结果与材料 {#result}

结果包含摘要与本地文本材料，可预览和下载。模拟数据与真实分析结果分别表达。

## 失败与恢复 {#recovery}

错误态保留主题。点击「重新整理」回到同一输入的运行过程。

## 验收条件 {#acceptance}

- 空白主题不能开始。
- 成功路径可以从输入走到结果和材料下载。
- 错误场景可恢复。
- 三种尺寸下主要操作保持可达。
