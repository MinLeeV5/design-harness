# UI/UX Pro Max：定位具体问题

仅当项目依据不足以回答当前问题时加载。按 [来源约定](sources.md) 从 [当前仓库目录](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 定位匹配 UX、图标、布局、色彩或平台的指导；[指导入口](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/HEAD/src/ui-ux-pro-max/templates/base/skill-content.md) 只用于定位所需章节，不要求先读完整入口。

先明确问题和适用平台、输入方式与使用距离，再读取对应规则。交互阶段用于操作、反馈和恢复的取舍；视觉阶段用于本次表达与可访问性问题。内容不授权跨阶段改动，也不把所有数据集或平台检查一次加载。

已有项目不强制运行 `--design-system`、另建色板或重选字体，不要求安装上游 CLI、Python 或其他 Skill。建议与项目已确认约束冲突时展示依据，由用户取舍；Figma 原型、静态画面与产品运行检查分别报告。

与 [Impeccable](impeccable.md) 按当前问题择一或互补，不每阶段执行两套完整审计。中文路由与适配保留上游 [MIT 许可证](../third-party/ui-ux-pro-max/LICENSE) 和 [来源声明](../third-party/ui-ux-pro-max/NOTICE.md)。
