# 当前交互交付检查

在主流程、每条分支的交付点检查本次范围，不为一次局部修改重跑全部路径。

- **任务与顺序**：骨架对应用户已确认的目标；主流程已确认才展开分支；未做、暂缓与不适用清楚区分。
- **可体验产物**：真实起点、触发条件、目标和返回/退出可回读；没有不存在的目标、遮挡或意外死路。可见流程箭头不能代替 reactions。
- **用户理解**：真实内容与操作尺寸足以判断交互；短标签、反馈、后果和恢复方式清楚，必要关系用可编辑图示。
- **证据边界**：连接配置、实际点击、用户确认、产品运行分别报告；原型无法完成时保留缺口，请用户决定调整范围或补足能力。
- **可恢复交付**：需求 Page 与交接记录可读，链接、版本、当前分支、确认范围和待验证项与真实产物一致。截图检查文档层级、文本与画面，而非证明产品运行。

制作错误在授权范围修正；新的行为取舍由用户决定。检查通过不等于用户批准；交互阶段完成也不批准视觉或全局知识变化。
