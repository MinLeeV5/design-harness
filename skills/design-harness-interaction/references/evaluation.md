# 本阶段验证

按[交付保真](../../../shared/references/fidelity.md)检查实际工作区与产物，不凭文字声明推断完成。

- 需求明确是局部流程、局部视觉还是完整 UI，登记页面、适用壳层、控件、状态和排除项。
- 设计归属符合项目组织模式：持续更新主稿或维护对应独立设计；单次拆分有用户明确要求，未改写默认或自动合并。持续迭代保留已接受内容，并验证本次变化影响的关联页面。
- 多方案已先讨论和确认，再按数量独立实现任务；不同页面组织均完成实际体验，局部融合适配状态与跨页依赖，历史来源、版本和最终所选写回分别可查。
- 已从实际入口操作主路径与必要菜单、弹层、校验、恢复和离开保护；预置场景与真实可达路径分别记录。
- 沿用控件的触发、层级、固定和滚动行为与基线核对；本地模拟没有被计为真实服务验证。
- 已按[打点覆盖与五维模板](../../../shared/references/interactions.md#何时需要打点)核对本次交互变化，必要说明已主动补齐或更新；新条目按需组合维度、每维度以一句话为主，无空项、重复摘要或界面复述，必要分支、恢复与风险边界清楚，可转成验收步骤。准确的已有条目直接复用，未确认规则明确标识，不以打点数量、字数或格式通过代替内容检查。
- 独立交互文档通过协议校验，正文、条件与真实 DOM 定位相符；从实际入口跨页，验证状态、说明条件、稳定目标和离开保护。PRD、场景与实际行为相符，当前缺失及未核实行为在交接中可见。
- 已按[共同维护与交接](../../../shared/references/handoff.md)完成过程维护、工程检查和交接；公共增量有授权与受影响需求的验证，按请求导出的实际 HTML 已通过离线检查。未请求导出不作为缺项。

操作见[预览与导出](../../../shared/references/preview-export.md)。本地模拟、源应用 Mock 与真实服务各自报告，检查和导出不等于用户验收。
