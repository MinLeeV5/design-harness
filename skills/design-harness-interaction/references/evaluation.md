# 本阶段验证

按[交付保真](fidelity.md)检查实际工作区与产物，不凭文字声明推断完成。

- 需求明确是局部流程、局部视觉还是完整 UI，登记页面、适用壳层、控件、状态和排除项。
- 已从实际入口操作主路径与必要菜单、弹层、校验、恢复和离开保护；预置场景与真实可达路径分别记录。
- 沿用控件的触发、层级、固定和滚动行为与基线核对；本地模拟没有被计为真实服务验证。
- 独立交互文档通过协议校验，正文、条件与真实 DOM 定位相符；从实际导航和顶部切页，验证页面、标注、说明同步以及离开保护。PRD、场景与实际行为相符，当前缺失及未核实行为在交接中可见。
- 页面采用完整 Spec，Catalog／Registry 与自定义 React 实现匹配；项目未产生可编辑工作台副本。
- 通过本入口 scripts/harness.mjs 运行 check --project <项目> 与 typecheck --project <项目>；通过只证明协议、类型和构建，不替代视觉与交互证据。

操作见[预览与导出](preview-export.md)。本地模拟、源应用 Mock 与真实服务各自报告，检查和导出不等于用户验收。
