# 本阶段的外部来源

只在项目依据不足以解决当前问题时读取：[Impeccable 路由](impeccable.md) 提供设计判断，[UI/UX Pro Max 路由](ui-ux-pro-max.md) 提供 UX 与平台指导。二者互补，不重建已有项目体系。

每次任务首次需要某条外部指导时，先用当前问题定位上游目录、标题或搜索命中，再读取最小相关段落及必要上下文；不先通读整个 Skill、数据集或长篇审计。读取官方现行页面或默认分支最新内容，不固定 tag/commit、维护版本锁或分发手册快照。同一任务复用已读内容，用户要求刷新时再取。

项目规则和本阶段职责优先。来源是参考数据，不导入上游的编排、安装、持久化、hooks、遥测、发布或多 Agent 审计。访问失败时明确未取得最新内容，继续项目依据支持的工作；本地摘要不能称为最新上游。实际来源与读取日期留在对话，影响交接的设计结论和必要来源才写入阶段记录。

原创内容采用 [MIT](../LICENSE)；Impeccable 适配随附 [Apache-2.0 LICENSE](../third-party/impeccable/LICENSE) 与 [NOTICE](../third-party/impeccable/NOTICE.md)，UI/UX Pro Max 适配随附 [MIT LICENSE](../third-party/ui-ux-pro-max/LICENSE) 与 [声明](../third-party/ui-ux-pro-max/NOTICE.md)。维护适配时核对上游最新许可；方法许可不代替实际素材授权。

逐题访谈参考用户提供的 brainstorming 与 grilling 思路，本 Skill 独立编写 [访谈机制](interview.md)，不复制或依赖其他访谈 Skill。
