# 插画与功能示意图

需要选择、制作或检查插画/示意图，以及 Init 登记其既有风格时加载。先按 [视觉资产选择](visual-assets.md) 复用适用 Library。Init 围绕存量和已批准的实现补齐，不为盘点主动生成新风格；正式插画在交互确认后的视觉阶段完善。

## 方法依据与表达任务

需要补充构图与表达判断时，按 [来源约定](sources.md) 查阅 [IBM 插画原则](https://www.ibm.com/design/language/illustration/overview/)；需要研究产品中使用插画的场景时，可查阅 [Atlassian 插画指导](https://atlassian.design/foundations/illustrations)。二者是在线阅读来源，未随包复制其正文、品牌风格或图形素材，具体范围见 [来源声明](../third-party/visual-assets/NOTICE.md)。

为当前图形写清一项主要表达任务，例如让用户看懂连接关系、找到操作位置或理解当前状态；不能只写“让页面更好看”。先判断图形是否比必要短文更易理解，再决定类型：

| 类型 | 制作路径 | 关键约束 |
| --- | --- | --- |
| 功能示意图 | 用 Figma 原生图形/矢量与原生 TEXT 组织实体、连接、方向、步骤或位置 | 图中设备、操作与关系有产品依据，结构可编辑；低保真仅画交互判断所需信息 |
| 情境插画 | 先复用适用素材，确有缺口再按当前上下文调用图像生成/编辑能力 | 表达情境或状态，沿用项目风格；装饰不能暗示不存在的产品功能 |

两种图形共存时把准确的关系、标签和操作提示保留为可编辑层。生成位图不承担需要精确修改的连接、步骤或关键文字。

## 从上下文形成制作说明

在对话和现有设计依据中收敛以下内容，不强制创建本地 brief 或新审批文件：

- **表达目的与事实**：目标用户、所处任务/状态、应理解的主要信息，主体及其关系；不允许画出的错误连接、能力或状态。
- **版面条件**：目标槽位尺寸/比例、实际显示尺寸、视觉重心、文案/操作区域的留白、背景或透明要求、主题模式。
- **项目风格**：真实参考资产，造型复杂度、线条/填充、视角、比例、角色与物体的一致性，以及可使用的项目色彩规则。已有方向直接沿用；图像不能反向覆盖产品 token。
- **交付方式**：原生可编辑图形或生成位图、可替换内容与裁切边界；操作标签、重要说明和需本地化的文字保留原生 TEXT。

把具体规则带入制作或生成提示词；参考图要说明它用于风格、主体还是编辑目标，以及必须保留的部分。已有参考先查看实际图像，不凭文件名推测内容。

## 制作与迭代

功能示意图先搭出实体和必要连接，再检查方向、顺序与位置，最后应用项目样式。精确结构默认用可编辑图形；复用图标时按 [图标方法](iconography.md) 保持家族一致。

情境插画有生成需求时，发现当前可用工具并加载它要求的 Skill 或说明，不把特定服务、模型或本机路径设为运行依赖。在已批准目的和风格内先制作代表性样图：检查实际输出，针对主体、构图或风格偏差进行编辑/重生成；保持已正确的部分，避免每轮无目的地更换风格。

样图满足既有依据后再扩展同系列，用同一组参考与视觉规则约束后续画面；单张图不额外扩成系列。新视觉方向或影响理解的分歧，用样图结合当前访谈一次讨论一个问题；既有授权和明确确认直接承接，不把每张图变成新的审批点。

## 导入与版面验收

使用当前连接器支持的图片填充/资源导入或原生矢量能力，放入本次已授权节点。回读实际类型、尺寸与引用，再检查目标画面的真实截图：

| 检查 | 应能确认什么 |
| --- | --- |
| 语义与事实 | 主体、数量、状态、连接及操作位置符合依据，没有虚构产品能力；表达与用户当前情境匹配 |
| 构图与阅读 | 主要信息清楚，必要文案和操作空间保留，细节不干扰主任务；文字仍可编辑且可读 |
| 系列一致性 | 视角、物体/角色比例、线条/填充、细节密度与项目配色在相关画面间一致 |
| 图像质量 | 在实际槽位检查裁切、留白、清晰度、边缘及背景；透明要求用真实 alpha 和目标背景检查，棋盘格图案不等于透明 |
| 可复用与来源 | 原生图形与位图如实分类，实际定位和必要使用约束写入 [资源说明](../assets/resource-card.txt)；新增认可风格进入获准的知识增量 |

生成成功、外链、提示词或占位框都不能代替 Figma 中的实际交付。提示词与临时下载地址留在任务中；项目只沉淀获准的代表资产、表达规则与使用边界。

生成或导入能力不可用时说明具体未完成项，继续独立部分。可编辑示意图只有在能表达同一目的时才可替代；需要改变已确认交付方式时给出具体选择，不伪称目标格式已完成。
