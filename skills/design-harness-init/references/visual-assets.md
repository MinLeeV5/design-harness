# 视觉资产选择与 Library

Init 在设计风格模块建立项目认可的来源与复用规则；Design 按需求读取并复核。使用 [来源蓝图](../assets/library-sources.txt) 登记引用，相关变量、组件、模板仍归原有模块，不新增知识大类，也不复制整个团队资产库。

本页负责来源发现、适用性与资产类型选择。选用、制作或检查某类资产时，再读下表对应方法；不一次加载全部图形指导。Init 只盘点已有规则与代表资产，按已批准的实现依据补齐；Design 在当前阶段制作所需资产，不因加载方法而扩大范围。

## 查找顺序与适用性

1. 读取项目的 `style/library-sources` 资源或现有同义索引，以及本次相关的风格、token 和组件。来源没有登记时按当前需要定向发现，不以此要求重做整个 Init。
2. 优先找已确认、适用于本平台/主题的本地资产和文件已启用的团队 Library；仍有缺口，再查可访问且相关的其他团队/组织库。库已启用不等于所有资产均获项目认可。
3. 依据语义、使用尺寸、状态、描边/填充、主题和品牌规则判断匹配。查名称、近义词与实际预览，不能仅凭同名或一个空查询判为没有。
4. 区分“可复用”“存在但不适用”“在已查范围内未找到”“无权限/能力不足未核实”。保留当前调查边界与未完成分页，工具不可访问不是资源不存在的证据。

项目明确约束优先于库中的默认样式。颜色优先使用适用的语义变量/样式及其模式，不因新增插画另起一套产品色板；团队库与项目已确认规则冲突时展示具体差异，再讨论取舍。

## 按当前工具发现，不绑定连接器

先遵循 [工具选择](figma-operations.md) 的连接和文件核对。工具名只用于发现线索，实际参数以当前契约为准：

- 有 `get_libraries` 等能力时，区分文件已启用库与可添加库；按所需范围分页，再用库限定的 `search_design_system` 等搜索具体资源。
- 有 Console 的 `figma_get_library_components`、`figma_get_library_variables` 等能力时，按已知来源库文件查找；不能把“查一个已知库文件”宣称为“列出了整个 Teams”。
- 检索用的 `libraryKey`、库 `fileKey`、组件/变量 key 与 nodeId 含义不同，不互相替代；参数必须来自真实返回值。文件绑定工具与活动文件工具混用前重新核对目标。
- 缺少目录能力时，可用当前可访问的 Assets/Library 界面或已核实库链接继续定向查询。只读盘点不导入组件、不启用库、不为测试创建节点。

## Init 登记，Design 复核

Init 按现有模块确认具体来源：名称、可再次定位的库链接/标识、用于什么、不适用于什么、图标家族与标签规则、插画表达目的与系列风格、色彩规则、代表性实际资产及可访问范围。按需从下方专项方法选择检查维度，记录项目已存在的做法；未知项如实标注，不把社区示例参数当成项目事实。持久化引用以真实库和资产定位为准；会话临时检索句柄留在任务中，不冒充永久地址。

Design 使用前检查当前访问及资产适用性，复用真实实例、变量/样式绑定；Frame、矢量和位图按实际类型记录。库的发布状态变化或具体引用失效时只补查相关项，不全团队扫描。新增认可来源或视觉规则在最终知识增量中确认回写。

来源登记与库管理分开：在已授权需求 Page 使用可用实例不等于获准编辑源主组件、替换全局变量、改变文件订阅或发布团队库。需要超出当前范围的库操作时，先备好具体资产、原因及影响，再确认该增量；已有明确授权直接执行。

## 按资产类型加载方法

| 资产 | 默认方式 | 判断重点 |
| --- | --- | --- |
| 通用图标 | 项目/团队库优先；无合适资产时查可用的成熟矢量图标来源 | 按 [图标设计](iconography.md) 检查含义、家族、实际尺寸与状态，必要缺口按同一体系补矢量 |
| 功能示意图 | 用原生可编辑图形或矢量表达连接、步骤、位置与状态 | 按 [插画与示意图](illustration.md) 的功能示意路径核对关系和方向、产品能力与可编辑性 |
| 情境插画 | 先查适用插画库；有需要且缺少合适资源时按需求生成 | 按 [插画设计](illustration.md) 明确表达目的，制作代表样图并检查系列一致性及实际版面 |
| 色彩 | 复用已批准的语义 token/样式与主题模式 | 不从图像取色或社区配色自动覆盖项目色彩；必要新增按确认范围建立 |

低保真阶段只补判断交互所必需的图示；正式插画在交互确认后的视觉阶段完善。图形有明确表达任务才加入，不给每屏强制配图。必要的动作短标签、输入标签、操作后果与错误恢复保留；不能只靠陌生图标或颜色传意，触屏关键说明不依赖 hover。

社区方法的读取和引用边界见 [外部来源](sources.md) 与 [视觉指导来源声明](../third-party/visual-assets/NOTICE.md)。方法参考、可复用素材和生成工具分别选择；有指导文档不等于拥有素材或具备生成能力。
