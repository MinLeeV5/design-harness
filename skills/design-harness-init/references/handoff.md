# 交接与恢复

恢复先读当前需求 handoff.md、manifest.json、requirement.md 和必要源文件，核对真实产物与固定基础。
项目规则、用户已确认决定和本次授权优先；不中断重做已完成探索，不将工具成功或版本存在当作验收。

交接保留目标与范围、当前任务、已确认决定及理由、关键反馈与实际变化、当前页面/场景/候选及源文件或固定交付定位、
实际检查及边界、真实验收与批准的公共增量、未决项和下一步。
不保存对话全文，不编造用户批准，不自动晋升知识。需求验收不自动批准全局基础变更。

授权按完整任务或明确局部范围承接；在范围内完成必要页面、状态、验证和修复，不固定逐页逐状态索取放行。
未决问题会改变已确认业务行为或交付边界时，只对变化部分重新对齐。
Init、交互、视觉和回写继续由用户显式启动；交互与视觉编辑同一可运行产物。
