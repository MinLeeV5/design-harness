# 初始化工作流

1. 读用户目标与项目约定，盘点规范、代表界面、组件、资源和当前行为。只读业务代码，不建立运行依赖。
2. 承接已有基础；缺失时按最有价值的模块共创意图、范围和复用边界，不为形式增加访谈。
3. 按[模板职责](workspace.md)建立独立目录，在 foundation 中记录事实、设计描述、Token 和组件。默认值标为草稿，来源与未来设计分开。
4. 先抽当前任务所需组件与布局模式，提供代表实例，检查真实画面、键盘和状态。图片按[资产方法](assets.md)处理。
5. 维护基础版本、确认状态与说明；公共改动不传播到既有需求。交付基础位置、检查与待补项后停止。

仅初始化不自动生成需求。通用示例明确示例身份；项目知识不得写入插件分发资源。
