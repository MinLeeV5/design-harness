# 视觉取舍访谈

先承接上游已确认交互与项目视觉规范。只问当前仍影响表达或资产方向的问题，每次一个，给出推荐及具体理由；可从项目资产查询的事实先自行核实。

用实际画面或代表片段帮助选择，例如某个图标是否需要短标签、情境插画是否帮助当前任务、信息层级采用哪种项目内表达。只有必要分歧才给局部备选，不默认做多套完整风格；已有授权和明确委托直接沿用。

回答形成真实视觉决定后更新 [交接记录](handoff.md)，关联对应产物版本。记录不复制全部对话。用户确认局部方向不代表已确认未展示的全部画面或知识回写范围。

发现问题涉及操作语义、状态、导航或恢复方式时，说明位置、影响及建议，由用户决定是否返回交互阶段。视觉访谈不能替代上游交互决定。
