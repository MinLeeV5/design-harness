# 本阶段验证

按[交付保真](../../../shared/references/fidelity.md)检查实际工作区与产物，不凭文字声明推断完成。

- 已在相同实际视口、上下文和可比内容下渲染基线及设计，逐区记录对照结果和证据。
- 当前设计归属与项目组织模式及本次明确选择一致；未因视觉候选比较自动拆分需求、改变默认或合并独立例外，主稿已有页面与行为得到保留。
- 壳层、分割线、尺寸、间距、字体换行、图标资产、表面样式和滚动边界已核对，不只完成业务主体。
- 实际打开并操作必要菜单／浮层、交互及响应式状态；未验证状态和剩余差异明确保留。
- 候选的差异可见且不混作已确认基线；视觉保真、交互覆盖、行为真实性与用户验收分别报告。
- 多方案先讨论并确认范围与方向，再按所选数量实现真实可操作结果；比较使用相同任务基线和可比尺寸。融合保留来源、细化保留版本、再探索基于当前结果，最终接受前不写正式资源；未就绪方向不计为完成。
- 已按[共同维护与交接](../../../shared/references/handoff.md)完成过程维护、工程检查和交接；公共增量有授权与受影响需求的验证，按请求导出的实际 HTML 已通过离线检查。未请求导出不作为缺项。

使用本地自由批阅收集反馈时，按[批阅流程](../../../shared/references/preview-export.md#本地自由批阅)核对每条评语的页面、原截图与当前修改；解决状态由用户确认。

操作见[预览与导出](../../../shared/references/preview-export.md)。本地模拟、源应用 Mock 与真实服务各自报告，检查和导出不等于用户验收。
