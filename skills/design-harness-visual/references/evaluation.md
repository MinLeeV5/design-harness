# 当前视觉交付检查

在每个候选页、整合页、展开页/状态及完整交付的门禁核验当前范围；检查通过不能代替用户确认或下一项放行。

- **逐项范围**：每次只生成或复制获准的一页、单页一种状态或某候选的一个代表页；未为补连接、系列资产或排版提前生成其他项。实际稿展示后附下一项具体计划并等待，用户只要求修改时不向后推进。
- **逐项共创**：目标、候选、整合和展开页均检查关键取舍；围绕实际表达逐题给推荐、理由与代价，真实反馈落实为本项变化，未决问题先讨论。无新取舍说明沿用依据，不重访全套风格；只有下一项计划与认可询问不能算访谈，字段齐全不证明讨论或设计质量。
- **探索与比较**：目标和探索范围已确认，2–3 套候选逐项生成并达到共同代表范围后才统一比较；未生成候选明确待办，当前页不因候选尚未齐备而被要求批量补完。同一内容、状态、尺寸及交互约束下的差异、收益、代价与推荐理由可核对；小修改同样适用。
- **收敛依据**：候选制作验收不冒充最终选定；主方向、选择理由与融合范围来自真实回答。整合代表范围逐页确认后才逐项展开，风格确认不授权批量生成；代表稿与完整交付的确认范围分开。
- **承接范围**：来源版本有效，任务步骤、状态、触发条件、操作含义及恢复路径保持已确认交互；发现差异先报告，由用户决定是否返回。
- **真实画面**：在实际目标尺寸检查信息层级、对齐、间距、长内容和状态表达；图示帮助理解，必要标签、后果及提示未被删去。
- **实际资产**：Library 来源与访问范围明确；检查实例、变量/样式绑定、图标类型和一致性。插画已导入且在槽位裁切、透明背景和目标尺寸下可用，生成成功不等于交付完成。
- **原型保持**：复制映射、起点和已生成目标的连接有效；后续页尚未获准时记录待补，不误连旧稿或假造已连通，完整交付前补齐适用连接。实际点击与产品运行的证据分别说明，截图不能证明交互或无障碍运行通过。
- **可恢复交付**：当前讨论、真实结论及表达变化、当前项、方案链接、主方向及理由、融合内容、验收版本与下一项放行进入交接；未完讨论可继续，偏好未被当作稿件验收或继续许可。候选知识增量没有被写成项目默认规范。

参考 [视觉资产选择](visual-assets.md) 中当前类型的检查即可。项目规则优先，第三方审计只按问题取用。只修复本阶段制作问题，设计取舍与最终稿确认承接实际用户决定。
