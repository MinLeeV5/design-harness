# Design Harness · 视觉设计

在已确认交互范围内，先探索多个视觉方向，再收敛并展开设计。先读 [当前阶段工作流](references/workflow.md) 与 [交接和恢复](references/handoff.md)，核对上游版本、本阶段授权与已有进度。

| 当前需要 | 按需读取 |
| --- | --- |
| 获取项目视觉依据 | [上下文读取](references/context-loading.md) |
| 复用或补齐图形、颜色 | [Library 与视觉资产](references/visual-assets.md)，选定类型后再读图标或插画方法 |
| 确认视觉目标、比较方案与整合取舍 | [逐题访谈](references/interview.md) |
| 操作 Figma、组织产物 | [工具选择](references/figma-operations.md)、[视觉蓝图](assets/visual-delivery.txt)；写说明时读 [文档模板](references/work-templates.md) |
| 检查当前视觉交付 | [视觉检查](references/evaluation.md) |
| 需要补充方法或拟定设计语言增量 | [外部来源](references/sources.md) 或 [设计描述](references/design-description.md) |

发现交互问题时提出影响与建议，由用户决定是否返回交互阶段。交付确认稿、资产来源与候选知识增量后停止，Harness 回写由用户另行启动。
