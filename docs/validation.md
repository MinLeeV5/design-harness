# 验证范围

## 自动检查

    npm ci
    npm run check

Node.js 22+、ESM、内置 node:test。依赖由锁文件管理，首次安装后自动检查不访问业务服务。

架构校验随 validate 和打包执行：使用锁定的 @babel/parser 开发依赖分析 JS、TS 与 TSX 导入，检查 frontend、preview、backend/http、backend/services、backend/adapters、contracts 与 CLI 的相对导入边界、移动后缺失引用、前端请求集中和共享协议的运行时独立性。校验器回归覆盖允许依赖、反向依赖、混合及跨行导入、动态导入、重导出与缺失模块，并排除注释和字符串；它不替代类型、构建和行为验证。
结构校验检查四个显式入口、阶段与共享引用边界、唯一固定工具和公共业务模板、版本、品牌、marketplace 和许可完整性；退役回写入口即使只残留引用文件也拒绝分发。
分发测试覆盖完整插件初始化、四入口直连同一 CLI、三个设计阶段的工作区运行，以及单独 Skill 缺共享资源时的明确错误、全新路径解压、中文/空格路径、可重复 ZIP、SHA-256、拒绝覆盖与私有数据排除；产品讨论无需初始化工作区。
工作区测试验证协议引用、Spec 结构、Catalog／Registry 编译、实例属性范围、单一共享基础、当前插件按需导出、源文件导入边界、HTML/资源内嵌、无项目落盘下载、当前源更新、CLI 输出边界与原子替换，以及本地写回冲突；扩展依赖维护检查可能访问 npm 注册表，不访问业务服务。

## 真实浏览器

    npm run test:browser

需要本机 Chrome；测试使用 Playwright 驱动独立浏览器、临时设计工作区和本地服务，不访问 Figma、业务代码或服务。
新增页面／说明验收检查产品导航和工作台切页的双向同步、取消离开保护、共享会话数据保留、显式重置、实际状态触发标注变化、四种说明模式及离线阅读；对比回归检查两侧固定位置、切换焦点保留会话、任一侧页面跳转、双方离开保护取消的草稿保留、场景/视口联动、同目标标注与业务操作独立；协议检查覆盖 YAML、稳定 ID、来源、页面和目标。
检查重复列表的实例地址和高亮、未知／缺失动作与属性／组件错误的可见反馈，以及新建表单必填、实际输入、运行反馈、结果与材料、失败恢复、场景重置、说明定位、两候选、即时调参及源文件保存。
检查预览默认满幅、辅助面板默认收起；Header 的页面／场景文字入口紧接需求标题右侧，与实际导航双向同步，场景选项随页面筛选，取消离开保护时 Header 保持原页。右侧说明／机器人图标 Agent／工具入口分别打开或收起对应面板，也可直接切换；抽屉内部无重复 Tab，Esc 与关闭按钮恢复对应入口焦点。检查三种预览尺寸在开关面板时实际分辨率、缩放和位置不变，操作状态保留，关闭保留临时预览和聊天草稿。
检查标题旁本地／离线／提案状态图标的悬停、键盘聚焦和触屏点击说明，状态入口只展示图标并保留可访问名称；提案明确尚未写入，Esc 优先关闭状态说明且保留面板，浮层不改变画布布局并避让屏幕边缘。
检查实际 iframe 的桌面、窄窗口与手机宽度，以及 900／700／360／320px 工作台无横向溢出，Header 控件始终可见，覆盖抽屉处于视口内并避让换行后的完整 Header。
检查画面工具在桌面与窄屏均以 2×2 大图标加文字展示四项操作，覆盖标注开关、场景重置、方案对比及导出；离线保留禁用的导出入口与说明，单候选时禁用方案对比。
导出后从 file:// 在离线浏览器环境打开，检查交互、材料与资源，并确认未依赖 HTTP/CDN。
截图与结果仅写系统临时目录用于当次检查，结束清理，不在项目或分发中保留 evidence/。检查结论直接报告，必要未决项记入 handoff。
工作台滚动条专项在显示原生滚动条的浏览器中执行，检查说明、聊天、输入框、代码区和浮层长列表的原生滚动、滑块拖动与横向滚动，确认打开浮层不改变产品画布；检查触控和强制配色使用默认样式。分别验证工作台 CSS 和候选 iframe，确保产品自有滚动条样式保持，离线 HTML 沿用同一隔离边界。

## 真实项目的完整 UI 保真

通用模板浏览器检查证明运行能力，项目完整 UI 另按[交付保真](../shared/references/fidelity.md)核对指定版本和环境。
按可比视口、上下文、内容与状态下的基线及设计画面，逐区核对壳层、菜单、组件细节、分割、固定／滚动区域与响应式；实际操作入口、弹层、键盘和恢复路径。
视觉保真、交互覆盖、行为真实性及工程检查分别记录。源代码、本地 Mock、设计模拟和现网各有证据边界；预置场景不代替真实触发，未核实不计为通过。
检查数量不构成完成门槛，未取得现网证据不使用“已与生产一致”的结论；修正当前需求后重新导出，不将导出当作用户验收。

## 边界

协议或类型通过不能证明元素真实存在、候选审美质量、读屏体验、用户验收或生产后端能力。
DOM 定位由预览实际报告；有说明目标未出现时需在相应状态核对。数据、权限、Agent、外部文件和设备行为按真实产品另行验证。
测试使用合成数据，不创建真实项目任务，不模拟用户批准，也不以提示词匹配证明 Agent 会正确共创或恢复。
离线导出不自动登记已验收；文件可打开不能证明设计正确。


统一下拉使用真实 Chrome 点击和键盘验收，不通过隐藏原生 select 代替操作。覆盖九处接入、需求跳转、搜索与无结果、禁用原因、方向键仅高亮、Enter 确认、Esc 嵌套关闭与焦点恢复、外部点击／Tab、长列表滚动、320/360 窗口、触屏和离线 HTML。原有页面联动、保护与偏好检查使用同一公共浏览器选择助手，继续验证实际业务结果。

输入工具栏验收检查图标可访问名称、控件位于正文下方、附件移除、身份与模型独立、生成期间锁定及停止、模型切换与历史恢复、图片能力限制、认证缺失保留草稿，以及320/360宽度无溢出。连接测试覆盖元数据脱敏、只读RPC分页与UTF-8、缓存和刷新、超时退出、令牌保护，以及认证／推理成功／失败／取消分离；真实本机调用验证所选模型与接受写回。

本机偏好另验证首次交互默认、未发送即保存、跨进程与端口恢复、新旧会话继承边界、按模型恢复深度、失效回退、保存失败重试、原子替换与权限、并发局部合并、损坏／软链接保护，以及请求与历史的实际深度。测试注入临时或内存偏好存储，不污染真实用户偏好；真实调用在临时存储中验证显式深度与接受写回。

## 维护时选择检查

- 修改专业身份／Skill适配：检查实际指导加载、身份切换承接、当前画面与参考图传入；验证共享提案全部候选、完整提案阅读、统一接受、冲突及取消；使用真实本机 Codex 验证专业对话和修改。
- 修改协议/运行器：工作区测试、固定工具与项目组件类型检查、相关浏览器路径。
- 修改目录/架构边界：架构校验器回归、完整自动检查、类型检查、真实浏览器；公开入口与分发路径涉及迁移时，覆盖新路径打包解压、CLI 启动和离线导出。
- 修改评审工作台/产品预览：浏览器交互和必要尺寸截图。
- 修改 Skill 指令：引用与公共引用检查、实际工作流审阅；交互与视觉均须覆盖获准公共增量、受影响需求验证、交接和按需离线交付，不把文案测试当作行为验证。
- 修改分发：完整自动检查、新路径打包/解压、完整插件安装与四入口资源和引用检查；新会话实际发现 Skill 另行验证。
- 修改品牌：沿用[品牌说明](../assets/README.md)，单独检查浅深背景与小尺寸；普通 HTML 重构不改品牌图形。

真实项目试点应通过分发的能力创建自己的工作区，记录反馈再修通用能力，不把项目专用实现写回通用模板。

导出检查实际点击工作台下载按钮，从下载的单个 HTML 断网验证交互和材料；CLI 检查读取当前需求与公共基础、资源目录外指定输出、重复替换及失败保留原输出。确认项目不创建 releases、sources 或清单。项目 Catalog 在隔离浏览器中校验，类型与构建不能替代。

Live Agent 自动测试使用结构化结果夹具验证预览、候选边界、取消、放弃、接受和外部编辑冲突；夹具不证明真实模型可用。改动运行适配器时，另使用已登录本机 Codex 在临时合成项目中生成并接受一次实际修改，仅报告结果，不保存模型输出。

统一Agent验收：初始和仅点选均无预铺控件；点选一次自动结束、不触发原动作且附加元素返回Agent；纯回答无文件修改；会话按候选隔离且保留完整消息和每轮活动；生成后调整实际改变Spec/CSS预览，继续对话基于已调节的临时源，接受后检查真实文件。验证请求、生成与校验活动、loading/耗时、取消、放弃、失败重试、外部编辑冲突及移动端。JSONL夹具覆盖UTF-8分块、过大/非法行、内部推理及原始工具/源码结果过滤。真实API和Chrome配合确定性模型结果只证明机制；另使用本机Codex实际完成一次生成、调节和接受后再报告模型链路通过。
