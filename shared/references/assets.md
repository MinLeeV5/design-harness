# 图形、设计描述与资产

Init 登记既有家族、适用边界与来源；视觉按页面目的选择图标、示意图或情境插画。
图标优先项目家族；准确关系与结构用 SVG/HTML 等可编辑表达；情境图需要时使用当前环境的 imagegen 工具或 Skill。
按生图工具要求读取参考图、描述用途、风格、尺寸、透明背景及系列一致性；生成后检查实际版面裁切、清晰度、背景与窄屏。
图片放在需求 assets，通过 ESM 导入；公共复用获准后才进入 foundation。记录来源、用途、许可或生成方式，生成成功不等于设计验收。
只做本任务所需资源，不预建图库，不将第三方 Skill 设为硬依赖；不可用时说明素材缺口。

设计描述关联视觉意图、理由、精确 Token 与边界，项目已确认规则优先。
按问题读取 [Google DESIGN.md](https://github.com/google-labs-code/design.md)、[Lucide](https://lucide.dev/contribute/icons/design-principles)、
[NN/g 图标评价](https://www.nngroup.com/articles/how-to-test-digital-icons/)、[IBM 插画](https://www.ibm.com/design/language/illustration/overview/)、
[Atlassian 插画](https://atlassian.design/foundations/illustrations)。外部手册和素材不随包复制，声明见[来源](sources.md)。
