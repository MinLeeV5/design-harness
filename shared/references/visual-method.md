# 视觉设计方法

先承接需求范围、已确认行为、审美方向和项目基础；查看当前实际截图、指定版本基线和相关参考，记录实际视口、内容与状态。依据不足时明确未核实范围，不能只用设计产物自身证明与源产品一致。

先对齐产品壳层、结构、组件与行为，再按几何与滚动、字体换行、边框分割、圆角阴影及精确资产收敛。复用真实 Token、组件、字体和图标；组件内部由 React/CSS 维护，组合与实例属性由 Spec 维护。按对象读取[资源协议](protocol.md)、[资产方法](assets.md)。

目标明确直接细化，有实质分歧时在相同内容、状态和尺寸下比较有意义的局部方向，保留选择理由。候选不自动成为已确认基线；修改权限由当前执行入口决定，本方法不扩展权限。

以真实视口验证布局，实际操作菜单、浮层、焦点、错误恢复和必要状态。缩略显示不能替代响应式验证；截图不能替代交互。既有交互契约变化需由对应入口承接。

按[交付保真](fidelity.md)提供可比画面、分区差异、操作结果与未验证项。交接记录最终选择、确认和来源；完成结论覆盖声明范围，工程检查和设计自检不代替用户验收。
