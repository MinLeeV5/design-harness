# 品牌资源

图标采用「组件核心」造型：四个独立模块围绕中心 H 留白组成菱形，表达可复用的设计组件与 Harness 约束。色彩参考 Figma 的模块配色。

## 图形与主题

| 位置 / 用途 | 目标颜色 |
| --- | --- |
| 上方模块 | 珊瑚橙 `#FF7262` |
| 左侧模块 / 插件主题色 | 紫色 `#A259FF` |
| 右侧模块 | 天蓝 `#1ABCFE` |
| 下方模块 | 青绿 `#0ACF83` |
| 浅色预览背景 | `#F6F7FA` |
| 深色预览背景 | `#171D2E` |

[icon.png](icon.png) 包含单个图形，不包含背景、文字或色板。四个色块在浅色和深色背景下保持一致，中心 H 和模块间隙透明。PNG 由图像模型生成，上表为设计目标色值，栅格像素可能存在细微色差。

插件清单的 `composerIcon`、`logo` 与 `logoDark` 都指向 `./assets/icon.png`，避免不同尺寸或主题的造型漂移。`brandColor` 为 `#A259FF`，由宿主决定具体呈现；它不会覆盖 Codex 的全局主题。需要查看实际大小时打开[品牌预览](../docs/brand-preview.html)。

保持图形的整体比例、四个模块的位置和中心留白；不拉伸、不加描边、不反转色块。根目录品牌资源仅用于插件展示，不是公开 Skill 的运行依赖。

## 生成记录

这份图标使用内置 imagegen，从用户选定的彩色组件方案提取为透明底的独立图形。最终[生成提示词](icon-prompt.txt)保留本次几何、配色、透明背景与留白约束；不随分发包携带未选方案。

网站和项目首页均为 [Design Harness GitHub 仓库](https://github.com/MinLeeV5/design-harness)。
